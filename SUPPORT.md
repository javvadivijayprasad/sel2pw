# Getting help with sel2pw

Thanks for using sel2pw. Here's how to get the fastest, most useful answer to your question.

## Before you ask

1. **Check the [README](./README.md)** — the "Quick start" and "Options" sections cover the majority of first-time questions.
2. **Check the [CHANGELOG](./CHANGELOG.md)** — if a behavior changed recently, it's documented there with the version and rationale.
3. **Search closed issues and Discussions** — someone may have hit the same thing already:
   - [Closed issues](https://github.com/javvadivijayprasad/sel2pw/issues?q=is%3Aissue+is%3Aclosed)
   - [Discussions](https://github.com/javvadivijayprasad/sel2pw/discussions)
4. **Look at the generated `CONVERSION_REVIEW.md` and `FILE_MAPPING.md`** in your output folder. Many "why did it do X" questions are answered inline in those reports.

## Where to ask

### GitHub Discussions (recommended for questions)

For open-ended questions, "how do I..." queries, migration strategy discussions, or sharing what you built, please use **[GitHub Discussions](https://github.com/javvadivijayprasad/sel2pw/discussions)**.

Discussions are better than issues for questions because:

- Answers stay searchable and voteable
- Other users can chime in with their experience
- The maintainer isn't the only person who can help you

### GitHub Issues (for bugs and feature requests)

Open an [issue](https://github.com/javvadivijayprasad/sel2pw/issues/new/choose) if you have:

- **A bug**: incorrect conversion output, a crash, a CLI error. Use the "Bug report" template.
- **A feature request**: a Java pattern sel2pw doesn't handle yet, or a new CLI flag. Use the "Feature request" template.

Both templates ask for the same core information: a **minimal Java input**, the **expected TS output**, and the **actual TS output**. Bug reports without a reproduction are hard to act on.

### Security issues

Do NOT open a public issue for security vulnerabilities. See [SECURITY.md](./SECURITY.md) for the private disclosure process.

### Commercial support

sel2pw is a research-stage OSS project maintained in the author's spare time; commercial SLA-backed support is not currently offered. If you're interested in dedicated conversion consulting for a large Java-to-Playwright migration, please open a Discussion or reach out via the contact info in the [CITATION](./CITATION.cff).

## What NOT to do

- **Please don't email the maintainer directly** for general questions or bug reports. Public channels (Discussions / Issues) let other users benefit from the answer, and keep the maintainer from becoming a bottleneck.
- **Please don't @-mention the maintainer** in unrelated issues asking for a response on your issue. Issues are prioritised by triage, not by pings.
- **Please don't post the same question in multiple places** (issue + discussion + email). Pick one.

Thanks for helping keep the project healthy.
